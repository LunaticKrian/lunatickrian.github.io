计算机组成原理总览

信息

计算机组成原理考察的是：如何用逻辑门搭建出能跑指令的机器。

本栏目按 408 考纲 组织，共 6 章：数据的表示和运算 → 存储系统 → 指令系统 → 中央处理器 → 总线 → 输入/输出系统。

知识结构​

章节导览​

章节核心内容408 考法
01 数据的表示和运算进位计数制、补码与运算、IEEE 754、ALU选择题高频，浮点 / 补码易错
02 存储系统主存组织、Cache、虚拟存储器大题高频（存储扩展、Cache 分析）
03 指令系统指令格式、寻址方式、CISC/RISC选择 + 大题（常与 CPU 结合）
04 中央处理器数据通路、控制器、流水线大题高频（数据通路 / 流水线分析）
05 总线总线分类、仲裁、定时、标准以选择题为主
06 输入/输出系统中断、DMA中断 / DMA 计算与辨析

学习主线：数据 → 存储 → 指令 → CPU → 总线 → I/O，前一章是后一章的“零件”，最后在 CPU 一章装配成整机。

计算机发展历程​

（1）以器件为标志的四代划分

代时间逻辑元件特点
第一代1946—1957电子管机器语言编程，体积大、功耗高
第二代1958—1964晶体管出现高级语言（FORTRAN）与监控程序
第三代1965—1971中、小规模集成电路操作系统逐渐成熟
第四代1972 至今大规模、超大规模集成电路微处理器诞生，微型计算机出现
提示

划分“代”的依据是逻辑元件（器件），而不是体系结构或编程语言 —— 高频选择题。

（2）标志性机器与人物

  • ENIAC（1946）：世界上第一台通用电子数字计算机（十进制运算，未采用存储程序，靠外部开关和接线编程）。
  • 冯·诺依曼：提出 存储程序 思想，确立五大部件结构，被称为“现代计算机之父”。
  • 图灵：建立可计算性理论（图灵机），被称为“计算机科学之父”；图灵奖 是计算机学界最高奖项。
  • 摩尔定律：集成电路芯片上的晶体管数目约 每 18~24 个月翻一番，性能也随之提升。

（3）软件与语言的发展

机器语言 → 汇编语言 → 高级语言 → 操作系统。软件与硬件在 逻辑功能上等效：同一功能可由硬件实现（快、贵），也可由软件实现（慢、廉价）。

计算机系统层次结构​

（1）冯·诺依曼机的组成

  • CPU = 运算器 + 控制器；主机 = CPU + 主存；输入/输出设备与外存合称 外部设备。

冯·诺依曼机特点（必背）：

  1. 由 运算器、存储器、控制器、输入设备、输出设备 五大部件组成；
  2. 指令和数据以 同等地位 存放于存储器内，并可按地址寻访；
  3. 指令和数据均用 二进制数 表示；
  4. 指令由 操作码 和 地址码 组成，程序在存储器中 按顺序存放，通常顺序执行，特定条件下可根据条件改变执行顺序；
  5. 以 运算器为中心，I/O 设备与存储器间的数据传送通过运算器完成（现代计算机已发展为 以存储器为中心）。
信息

核心思想：存储程序 —— 将程序（指令 + 数据）以二进制形式预先存入主存，机器启动后 自动、逐条地取指令并执行，无需人工干预。

（2）五个层次（自下而上）

层级名称说明
M0微程序机器微指令由硬件直接执行，是传统机器的硬件内核
M1传统机器语言机器机器指令由微程序（或硬布线）解释执行
M2操作系统机器由机器指令解释 系统调用（广义指令）
M3汇编语言机器汇编程序将汇编代码翻译成机器指令
M4高级语言机器编译程序 / 解释程序处理高级语言
  • M0、M1 是 硬件（实际机器）；M2~M4 是 软件（虚拟机器）；M2 是软硬件交界的“夹层”，向下管理硬件、向上提供接口。
  • M1（指令集架构，ISA）是软件与硬件的分界面：软件只需面向 ISA 编程，硬件实现细节对其透明。

（3）翻译与解释

  • 翻译（编译）：先把高级语言程序 整体 翻译成目标程序（机器码），再执行，如 C 语言。
  • 解释： 逐条 取出语句翻译并立即执行，不生成目标程序，如 Python。
  • 汇编语言必须经 汇编程序 翻译为机器语言后才能执行。
透明性考点

“透明” = 看不见 = 无需关心。例如 微程序对机器语言程序员透明；而通用寄存器、PC 对汇编语言程序员 不透明。判断口径：上层使用者不需要了解的下层实现细节，即对该层透明。

计算机性能指标​

（1）CPU 性能

  • 机器字长：CPU 一次能处理的二进制位数（= 内部寄存器 / ALU 宽度）。字长越长，精度越高、速度越快。
  • 主频 f 与时钟周期 T：T = 1 / f。如主频 2 GHz → 时钟周期 0.5 ns。
  • CPI：执行一条指令所需的平均时钟周期数。
  • CPU 执行时间 = 指令条数 × CPI × 时钟周期 = (指令条数 × CPI) / 主频。
  • MIPS（每秒百万条指令数）= 指令条数 ÷ (执行时间 × 10^6) = 主频 ÷ (CPI × 10^6)。
  • FLOPS / MFLOPS：每秒浮点运算次数，用于科学计算场景；与 MIPS 不能直接换算。
注意

主频高 ≠ 程序一定快：程序时间由 指令条数 × CPI × T 三要素共同决定。CISC 换 RISC 往往“指令条数 ↑、CPI ↓”，必须整体计算再下结论。

（2）存储与传输

  • 主存容量：可寻址空间由 MAR（存储器地址寄存器）位数 决定，容量 = 2^MAR × 存储字长。
  • 数据通路带宽：数据总线一次并行传送的位数。
  • 总线带宽：单位时间内总线传送的数据量 = 总线工作频率 × (总线宽度 / 8)。

（3）系统级指标

  • 响应时间：从发出请求到收到响应的总时间（CPU 时间 + 等待时间）。
  • 吞吐量：系统在单位时间内处理的请求数 / 任务数。
  • 周转时间：作业从提交到完成所经历的时间。
  • 基准程序（Benchmark）：用标准程序集（如 SPEC）测量综合性能，比任何单一指标都更全面。

（4）单位辨析：容量看 1024，速率看 1000

单位存储容量（2 的幂）传输速率（10 的幂）
K2^10 = 102410^3 = 1000
M2^2010^6
G2^3010^9
T2^4010^12

例：主存 1 KB = 1024 B；网络 1 kb/s = 1000 b/s。注意 小写 b 是 bit，大写 B 是 Byte，相差 8 倍。
