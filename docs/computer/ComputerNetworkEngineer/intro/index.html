【软考】网络工程师

以华为eNSP模拟器为主进行练习，同时熟悉思科的关键命令作为补充。

公开资料：https://github.com/xiaomabenten/network_engineer

eNSP 模拟器，使用Windows操作系统进行安装使用：https://github.com/yuchen-ya/eNSP-install-win

PS：后续自己搭建网络工程师的知识库，引入这个安装模块，进行维护。

题型：​

  • 上午题：75道选择题
  • 下午题：4道大题

计算机软考中级网络工程师的下午考试科目为 《案例分析》 ，近年来其题型和分值构成比较稳定，通常包含4道主观大题，满分75分，45分及格。考试内容侧重于网络规划、设计、配置与故障排查等实操能力。

📝 核心题型与分值分布​

下午的4道大题通常有明确的分工，根据近年的真题分析，其构成大致如下：

  • 第一题（20分） ：网络规划与设备组网。该题通常结合一个具体的网络拓扑场景（如企业园区网、校园网），考查IP地址与子网划分（含IPv6规划）、网络设备选型、以及基础的设备配置（如交换机VLAN、DHCP等）。
  • 第二题（20分） ：网络安全与设备配置。此题重点考查网络安全技术的应用，常涉及防火墙策略配置、ACL访问控制列表、VPN等，要求考生根据安全需求完成配置或分析安全风险。
  • 第三题（20分） ：网络服务与管理。该题可能考查Windows Server或Linux环境下的常见网络服务配置，例如DNS、DHCP、Web服务器等，也可能涉及网络管理协议（如SNMP）的应用。
  • 第四题（15分） ：路由与交换高级配置。此题为华为设备配置的专项考查，常涉及静态路由、RIP、OSPF、BGP等路由协议，以及RSTP/MSTP等交换技术，要求考生补充完整配置命令或分析配置原理。

注意：以上为常规分布，实际考试中题型的顺序和具体分值可能会有微调。例如，2026年5月的真题中，题型分布为：试题一（20分，运维故障+安全）、试题二（15分，交换+DHCP配置）、试题三（15分，综合布线+无线规划）、试题四（25分，静态路由+OSPF+BGP）。

📈 近年考查趋势与高频考点​

综合近几年的考试情况，下午题呈现出以下趋势，备考时可以重点关注：

  • IPv6内容比重增加：IPv6的地址规划、过渡技术（如双栈、隧道）等考点在下午题中的分值占比有明显提升，需要重点掌握。
  • 新技术开始出现：SD-WAN（软件定义广域网） 和云网融合等新概念在近两年的考题中开始出现，虽然当前分值不大，但建议建立基本认知。
  • 故障排查是核心能力：题目常以“网络出现故障”为背景，要求考生根据现象分析原因并给出解决命令，这要求对网络协议原理有深入理解。
  • 配置命令以华为设备为主：路由与交换的配置题基本以华为设备的命令行为主，需要熟悉华为VRP系统的常用命令。

💡 备考建议​

针对下午案例分析，建议采取专项突破的策略。可以按照IP地址规划、设备配置、故障排查、安全策略等模块，分别进行集中练习，将每类题型的解题思路和常用命令模板化，再通过整套真题模拟来检验综合应用能力。
