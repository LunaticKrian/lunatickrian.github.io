假设：图层 A 是你要借用的形状，图层 B 是你要应用选区的目标图层。 打开 图层面板 (Window → Layers)。 找到 图层 A（源形状图层）。 载入形状选区： Windows: 按住 Ctrl 键（Mac: 按住 Cmd 键）。 用鼠标 左键单击图层 A 的缩略图（小预览图，不是图层名字）。 画面出现蚂蚁线，表示已成功载入图层 A 的形状选区。 应用到目标图层： 在图层面板中，点击选中图层 B（目标图层）。 现在你就可以在 图层 B 上，对这个选区进行 填充、描边、调色、删除 等任何操作。

使用【色相/饱和度】工具进行颜色校正​

先使用【色相/饱和度】工具观察当前画面中的人物颜色，然后使用【色彩平衡】工具进行颜色的调整。

  • 拉高饱和度，调整画面的整体颜色风格；
  • 拉低饱和度，调整画面的白灰黑关系；（画面中从【近到远】的变化关系【灰白灰】）

调色：​

  1. 调色第一步：白平衡校准（调整照片的色温）

PS：目的是让照片中的白色是真正的白色，而不是偏蓝或者偏黄

使用【曲线】工具，Alt + 自动 -> 查找深色和对比对，能快速校准照片的白平衡

  1. 直方图：定影调/观察色调
  • 影调：照片的明暗
  • 色调：颜色的偏移

PS：黑白灰，并不属于色彩信息，而是属于明度信息（无论什么颜色，颜色的内部都有黑白灰）

任何像素中都有红绿蓝三种颜色，只是对应多少的关系。（其中某种颜色多，像素本身的颜色就会向某种颜色进行偏移）

在颜色直方图上，无论在任何明度区间里，占据直方图右侧的颜色就是画面中主导色

红、绿、蓝

  • 红 + 绿 = 黄
  • 红 + 蓝 = 洋红
  • 绿 + 蓝 = 青

影调：光影和色调​

摄影中我们通常把照片的明暗关系划分为三类：暗（低调）、灰（中调）、亮（高调）

通过【直方图】判断影调

PS：影调处理的目的：1.情感表达、2.氛围渲染、3.确定风格（影调就是明暗关系、色彩关系）

  • 低调（暗调）：忧伤、压抑、颓废、酷、神秘（拍摄风格：暗调情绪风、暗调情绪风、杀手、战争）
  • 中调：平稳、祥和、安静平和（日常记录、细节纹理多、胶片、港风）
  • 高调（亮调）：欢快、愉悦、开心、活力（拍摄风格：日系小清新、成长、青春成长、校园）

PS：拍照就是让该过曝的地方过曝，该死黑的地方死黑

冷启动决策（0～1000粉）​

  • 第一阶段「0～3个月」目标：积累可用素材
  • 第二阶段「3～6个月」目标：有1～2条小爆的内容
  • 第三阶段「6 个月后」目标：稳定接单/稳定合作

内容：​

  • 内容矩阵（建议比例 4:3:2:1）

内容形式对应平台：

根据二次元摄影赛道的规律，以下几种内容容易出爆款：

  • 合成前后对比（最容易爆）
- 形式：左原图/右合成成品，或视频渐变过渡
- 标题模板："从XXX到XXX，一张Cos照片的蜕变"
- 抖音上这类内容很容易获得高完播率
  • 热门角色 + 高质量合成
- 蹭热门番剧/游戏的流量
- 提前关注新番/新游戏上线节点，提前准备相关内容
- 比如原神新角色上线当天发相关合成，流量会很高
  • "普通人也能做到"的教学内容
- 降低门槛感，让新手觉得"我也能学"
- 标题模板："3分钟教你合成XX效果""一个技巧让Cos照片变大片"
- 这类内容在小红书收藏率极高
  • 反差感内容
- 拍摄现场很简陋 vs 成品很华丽
- 素颜/日常 vs Cosplay成片
- 反差越大，传播力越强
  • 情绪向内容
- Cosplay本质是对角色的热爱，讲你和Coser的故事
- "为了拍好这个角色，我们去了XX地方"这类叙事内容容易引发共鸣

2026年03月28日​

审美积累​

看图的思维逻辑，每次看一张好图时，问自己这 5 个问题：

  1. 构图：主体在画面什么位置？用了什么构图法则（三分法、引导线、对角线、框中框）？
  2. 光影：光从哪来？硬光还是柔光？明暗对比大不大？
  3. 色彩：主色调是什么？是互补色、类似色还是单色搭配？（你日志里已经学了这些，直接用上）
  4. 情绪：这张图传达了什么感觉？是通过什么元素传达的？
  5. 如果是我拍，我会怎么做？ — 这是最重要的一步

PS：色调、质感和大小三者相互作用极为重要

实操练习：

  • 拆解练习：选一张你喜欢的 Cosplay 成片，用截图工具在上面画线，标注构图线、光源方向、色彩分区
  • 模仿练习：找一张喜欢的图，尝试用相似的构图/光影去拍一张（模仿是学习审美最快的方式）
  • 对比练习：把同一场景你拍的和别人拍的放一起，找出差距在哪

素材收集：

  • Pixiv 日榜/热门（二次元插画）
  • 电影截图（电影调色、氛围渲染、构图设计、分镜设计）
  • 游戏原画（CG）

影调：

  • 光影：使用【色相/饱和度】调整图层 分析图片「黑白灰」（光影）关系

  • 色调：画面主要是什么颜色，渲染什么氛围，表达什么情绪

  1. 构图：人物主体在画面的中间位置，使用了引导线构图（使用人物）
  2. 光影：光从顶上来来，硬光，明暗对比大（画面背景为暗调、顶光把人物打亮）
  3. 色彩：暖色色调，单色搭配
  4. 情绪：华丽、唯美、孤独；通过八音盒金属 + 暖色顶光打亮人物 + 空气粒子光辉渲染气氛
  5. 拍摄需要使用橙色色卡 + 顶光（暖色调打亮画面），需要在人物的左侧打一个低机位的轮廓光，亮度低，能打亮腿部即可
